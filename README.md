# Планировщик

Веб-приложение для iPhone: задачи, календарь, списки покупок, привычки и фокус-таймер. Подходит для работы, учёбы, дома и выходных. Работает без интернета и ставится на экран «Домой» как обычное приложение.

## Возможности

**Задачи**
- Умный ввод на русском: `Встреча завтра в 15:00 #работа !!!` — дата, время, метка и приоритет распознаются сами.
  Понимает «сегодня / завтра / в пятницу / через 3 дня / 25.11 / 10 декабря», «утром / вечером», «на 1 ч», «каждый день / по будням / по понедельникам и четвергам / каждый месяц», «напомни за 15 мин», `@Список`.
- Несколько строк за раз — несколько задач (удобно вставлять список из заметок или мессенджера).
- Подзадачи, заметки, приоритеты, метки, длительность, повторы, напоминания.
- Свайп вправо — выполнено, влево — на завтра, длинный свайп влево — удалить. Кнопка «Отменить» после каждого действия.
- Выбор нескольких задач: перенести на сегодня/завтра, в другой список, сменить приоритет, выполнить, удалить.

**Экраны**
- **Сегодня** — прогресс дня, загрузка по времени (предупреждает о перегрузке), просроченное с переносом в одно касание, привычки дня, «Спланировать день» из ближайших и отложенных задач.
- **Списки** — «Входящие», «Предстоящие» по дням недели, «Важное», «Все», «Выполненные», свои списки с прогрессом, метки.
- **Календарь** — месяц с отметками, список дня и почасовое **расписание** (касание по свободному часу создаёт задачу на это время).
- **Привычки** — ежедневные, по дням недели или «N раз в неделю», счётчики (например, 8 стаканов воды), серии, тепловая карта месяца, процент за 30 дней.
- **Ещё** — фокус-таймер (помидоро) с привязкой к задаче, матрица Эйзенхауэра, статистика, шаблоны, поиск, настройки, резервная копия.

**Покупки**
- Товары сами раскладываются по отделам магазина (овощи, молочное, мясо, бытовая химия…).
- Количество в тексте: `молоко 2 л`, `яйца 10 шт`.
- «Часто покупаете» — добавление прошлых покупок одним касанием.
- «Снять отметки» — список снова готов к следующему походу в магазин.
- «Отправить список» — текстом в любой мессенджер.

**Шаблоны**: поездка, экзамен, запуск проекта, встреча, уборка, выходные, переезд, покупки на неделю. Свои шаблоны:
- любую задачу можно добавить в шаблон (карточка задачи → «Добавить в шаблон»), несколько сразу — через выбор задач → «В шаблон», весь список — «⋯» → «Сохранить как шаблон»;
- сохраняются подзадачи, заметка, приоритет, метки, длительность и повтор (даты — нет, чтобы шаблон подходил на любой день);
- шаблон можно применить новым списком или добавить его задачи в уже существующий список; задачи из шаблона можно убирать, сам шаблон — переименовать или удалить.

**Статистика** за неделю, месяц, год или всё время: выполнено и создано задач, доля сделанного в срок, дни с делами, среднее в день, рекорд, график по дням или месяцам, самые продуктивные дни недели и время суток, разбивка по важности, спискам и меткам, опоздания по срокам, фокус-таймер, привычки и итоги за всё время.

**Напоминания**
- «Один раз» — в нужное время, или «Несколько» — например, с 12:40 до 19:30 три раза: приложение само разделит период поровну (12:40, 16:05, 19:30).
- Можно напомнить в день задачи или заранее: за 1, 2, 3 дня или за неделю.
- Умный ввод: `Выпить таблетки напоминай с 12:40 до 19:30 3 раза`, `Встреча завтра в 15:00 напомни за 30 мин`.
- Пока приложение открыто, напоминание приходит окном со звуком; его можно отметить выполненным или отложить на 10 минут или на час.
- Закрытое веб-приложение iPhone будить не разрешает, поэтому кнопка «Добавить в Календарь iPhone» переносит напоминания в стандартный «Календарь» — он напомнит в любом случае, даже без интернета.

**Данные** хранятся на телефоне. В «Ещё → Данные и копия» можно сохранить копию (.json), восстановить её и выгрузить задачи в Календарь (.ics).

## Как открыть на iPhone

1. Опубликуйте папку через GitHub Pages: репозиторий → **Settings → Pages** → Source: *Deploy from a branch* → выберите ветку и папку `/ (root)` → Save. Через минуту появится адрес вида `https://<имя>.github.io/planirovk/`.
   (Для приватного репозитория Pages доступны на платном тарифе GitHub; иначе сделайте репозиторий публичным или используйте любой статический хостинг — достаточно загрузить файлы как есть.)
2. Откройте адрес в **Safari** на iPhone.
3. Нажмите **«Поделиться»** → **«На экран „Домой“»** → **«Добавить»**.
4. Запускайте с иконки — приложение откроется на весь экран и будет работать без интернета.

## Устройство проекта

Без сборки и зависимостей: обычные HTML, CSS и JavaScript.

| Файл | Что внутри |
|---|---|
| `index.html` | точка входа PWA |
| `app.css` | стили, светлая и тёмная темы |
| `js/01-core.js` | утилиты, даты, хранение, синхронизация, отмена |
| `js/02-logic.js` | задачи, повторы, умный ввод, покупки, шаблоны, привычки, экспорт .ics |
| `js/03-views.js`, `js/04-views2.js` | экраны |
| `js/05-sheets.js` | всплывающие окна: быстрый ввод, редактор задачи, списки, привычки |
| `js/06-main.js` | обработка нажатий, свайпы, таймер, напоминания, запуск |
| `sw.js`, `manifest.webmanifest`, `icons/` | работа офлайн и установка на экран «Домой» |
| `tools/build-artifact.mjs` | сборка в один файл для публикации в Claude |
| `tools/make_icons.py` | генерация иконок |

Локальный запуск: `python3 -m http.server` в папке проекта и открыть `http://localhost:8000`.
